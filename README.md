# إدارة الصيدلية السريرية

تطبيق ويب جاهز للعمل على الهواتف والأجهزة اللوحية، مصمم خصيصًا لاستخدام الصيادلة السريريين داخل الأجنحة الداخلية للمستشفى. واجهة بالعربية مع دعم كامل لاتجاه RTL، وتعمل دون اتصال بالإنترنت (تُخزَّن البيانات محليًا في المتصفح).

## الميزات

- **جناح كامل**: ١٠ غرف و٥٠ سريرًا (الغرف ١–٥ بها ٦ أسرّة، والغرف ٦–١٠ بها ٤ أسرّة).
- **حالات بصرية واضحة للسرير**: فارغ (رمادي) · مشغول بدون علاج (برتقالي) · مريض بعلاج (أخضر).
- **شاشة مريض كاملة**: غرفة + سرير + اسم + قائمة علاجات فقط — بدون تشخيص أو حساسية أو مسارات إعطاء.
- **إضافة علاج عبر bottom-sheet**: اختيار متعدد، تعديل الجرعة والتكرار قبل الحفظ، إضافة جماعية بضغطة واحدة.
- **تكرارات قياسية**: `1×1`, `1×2`, `1×3`, `1×4` + دعم قيم مخصصة (مثل «حسب القياس»).
- **لوحة إدارة الأدوية** (للمسؤول): إضافة/تعديل/حذف أدوية وجرعاتها الافتراضية — قابلة للتعديل حسب البروتوكولات المعتمدة في المستشفى.
- **تصدير PDF / طباعة**: قائمة أدوية المريض بترويسة احترافية وجدول وخانات توقيع.
- **تخزين محلي**: البيانات تبقى بعد إعادة التحميل وإغلاق المتصفح (localStorage).
- **بنية معيارية**: الترحيل إلى Supabase / PostgreSQL / REST API يستبدل ملف `js/remote-adapter.js` فقط دون لمس واجهة المستخدم.

## بنية المشروع

```
pharmacy-ward/
├── index.html              # الصفحة الوحيدة (RTL، safe-area، bottom-sheet)
├── css/
│   └── styles.css          # نظام تصميم mobile-first ( RTL، safe-area، طباعة)
├── js/
│   ├── medications.js      # 12 دواء تجريبي + قائمة التكرارات
│   ├── ward.js             # مولد بنية الجناح (10 غرف، 50 سرير)
│   ├── storage.js          # طبقة تخزين محلية (localStorage)
│   ├── remote-adapter.js   # قالب ترحيل لـ Supabase/REST (غير مفعّل افتراضيًا)
│   ├── ui.js               # دوال العرض (إحصائيات، غرف، أسرة، مريض، admin، طباعة)
│   └── app.js              # المتحكم الرئيسي (الأحداث، الحالة، التخزين)
```

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو قدم المجلد عبر أي خادم HTTP ثابت:

```bash
cd pharmacy-ward
python3 -m http.server 8765
# ثم افتح: http://localhost:8765/index.html
```

> لا يتطلب أي اتصال بالإنترنت للنسخة الأولى.

## سير العمل السريري

1. افتح التطبيق → اختر غرفة → اختر سريرًا
2. أدخل اسم المريض
3. اضغط «إضافة علاج» → اختر عدة أدوية عبر الـ bottom-sheet
4. عدّل الجرعة/التكرار إن لزم → اضغط «إضافة المحدد إلى المريض»
5. كل الأدوية تُضاف بضغطة واحدة

## لوحة الإدارة

اضغط زر ⚙ في أعلى الصفحة لفتح:
- إضافة/تعديل/حذف الأدوية
- ضبط الجرعات والتكرارات الافتراضية
- استعادة القائمة الافتراضية (مع تأكيد)
- مسح جميع البيانات (مع تأكيد مزدوج)

> ⚠ القيم الافتراضية في `js/medications.js` هي قيم تجريبية لأغراض العرض فقط. يتحمل مدير الصيدلية/المستشفى مسؤولية ضبط الجرعات والتكرارات وفق البروتوكولات المعتمدة محليًا.

## تصدير PDF

في شاشة المريض اضغط «🖨 تصدير PDF / طباعة» — سيتم إنشاء تقرير منسق يتضمن:
- ترويسة التطبيق والتاريخ والغرفة/السرير
- اسم المريض وموقعه
- جدول العلاجات (الاسم بالعربية + الإنجليزية + الجرعة + التكرار)
- خانات توقيع للصيدلي والممرض

## الترحيل إلى خادم مستقبلي

لاستبدال التخزين المحلي بـ Supabase / PostgreSQL / REST API:

1. عدّل `js/remote-adapter.js` لينفّذ نفس واجهة `PharmacyStorage` باستخدام `fetch` أو عميل Supabase.
2. في `js/app.js` استبدل `window.PharmacyStorage` بـ `window.RemotePharmacyStorage` بعد المصادقة.
3. لا حاجة لتعديل `ui.js` أو `ward.js` أو `medications.js`.

مخطط PostgreSQL مقترح موجود في تعليقات `js/remote-adapter.js`.

## القيود

- النسخة الحالية لا تدعم المصادقة أو تعدد المستخدمين.
- لا يوجد مزامنة بين الأجهزة في النسخة المحلية.
- الجرعات الافتراضية تجريبية ويجب مراجعتها قبل الاستخدام السريري.

## الترخيص

للاستخدام الداخلي في المستشفى. راجع فريق المعلوماتية قبل النشر.
